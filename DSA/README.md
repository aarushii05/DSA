# Data Structures & Algorithms Practice in Java

This repository contains solutions to Data Structures and Algorithms problems practiced on platforms like Codeforces, LeetCode, and college coursework, implemented in Java.

---

## Repository Structure

### Basic & Number Theory Problems
| File | Topic / Problem Description |
| :--- | :--- |
| `Basic.java` | Basic variable declaration and initialization |
| `BorrowBanana.java` | Codeforces 546A (Soldier and Bananas) |
| `CF1352A.java` | Codeforces 1352A (Sum of Round Numbers) |
| `CountComPrime.java` | Count composite and prime numbers up to N |
| `CountEvenOdd.java` | Count even and odd digits in a number |
| `CountKDigit.java` | Count occurrences of a specific digit |
| `DigitSum.java` | Sum of digits of a number |
| `Even.java` | Productive days counter based on conditions |
| `FindLargeDigit.java` | Find the largest digit in a number |
| `PalindromeNum.java` | Check if a number is a palindrome |
| `Prime.java` | Check if a number is prime |
| `Pythagorian.java` | Pythagorean triplet verification |
| `Reverse.java` | Reverse a given number |
| `Swap.java` | Codeforces 617A (Elephant step minimization) |
| `ThreeMore.java` | Track improvement days based on array values |
| `VectorSpace.java` | Codeforces 69A (Young Physicist - 3D vector equilibrium) |

### Array Problems (`array/`)
| File | Topic / Problem Description |
| :--- | :--- |
| `FirstArray.java` | Array initialization and display |
| `Max.java` | Find maximum element using ArrayList |
| `MoveZero2.java` | Move non-zero elements preserving order and zeros to the back |
| `PrintMinMax.java` | Second largest element in an array |
| `Searching.java` | Linear search for target in an ArrayList |
| `Twin.java` | Array input processing |

## How to Run

Compile and run any file using Java CLI:

```bash
javac <FileName>.java
java <FileName>
```
